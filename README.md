# Caffe-Z ☕

A modern, fully responsive landing page for a premium coffee shop experience. Built with pure semantic HTML5, modern CSS3 (including Grid and Flexbox), and vanilla JavaScript. 

This project showcases clean code standards, dynamic interactivity, and user state preservation without relying on heavy external frameworks.

## 🚀 Live Demo
https://ayaalsaudi6-blip.github.io/Booking-Website/

## ✨ Features
* **Modern UI/UX Design:** Clean layouts structured with custom typography and elegant imagery.
* **Manual Dark Mode Toggle:** Seamless theme switching with proper background and card color styling.
* **Table Reservation System:** Form validation that securely captures user details and stores them using `localStorage`.
* **Dynamic Toast Notifications:** Micro-interactions that give instant visual feedback when items are favorited or tables are reserved.
* **Fully Responsive:** Optimized layouts across mobile, tablet, and desktop viewports using CSS Grid and media queries.
* **Smooth Scrolling:** Enhanced native browser navigation across page sections.

## 🛠️ Tech Stack
* **Markup:** Semantic HTML5
* **Styling:** CSS3 (Flexbox, Grid, Media Queries, Custom CSS Transitions)
* **Scripting:** Vanilla JavaScript (ES6+, DOM Manipulation, LocalStorage API)
